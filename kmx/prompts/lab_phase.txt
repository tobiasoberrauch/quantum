kickmix circuits (.kmx) for a fixed quantum arithmetic task (spec in the user message).

WORLD VIEW
  Think in phases, not values: produce exp(2 pi i/sqrt(x)) directly without
  materialising 1/sqrt(x) where possible - phase kickback, lookup of phase
  contributions, phase polynomials, splitting the phase into a cheap coarse part
  and small residual rotations. Every fine rotation costs ~7 Toffoli-equivalents.

COST MODEL (the only thing that counts)
  score = Q x C, lower is better. Q = largest qubit index + 1 (every index up to the
  maximum counts, so reuse low indices). C = mean Toffoli-like gates (CCX, CCZ, CSWAP)
  per shot + T/4 + n_rot x (0.56*log2(1/eps) + 5.3)/4, where n_rot counts fine Z_POW
  rotations and eps = pi * min_x(tol(x) - |error(x)|) / n_rot. X, CX, CZ, Clifford
  phases (Z, S) and HMR measurements are free. tol(x) = 2^-24 * beta/sqrt(x) turns (beta = 1) FALLS with x.
